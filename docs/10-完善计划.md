阶段⑤实际落地内容（真机联调，批次七；MuMu x86_64 / 目标应用 com.notevault.app）：

- **联调暴露并修复的真产品 bug**（按危害排序）：
  1. **sidecar 假死**：PyInstaller onefile 的 bootloader 父进程先于 python 子进程退出，宿主 `wait()` 返回被误判为「sidecar 已退出」→ 孤儿子进程成僵尸、通道B 瘫痪。修复：alive 唯一裁决 = stdout 管道 EOF（读泵）；wait() 只归收僵尸；单行解码错误丢行继续不弃管线；spawn 强制 `PYTHONUTF8=1`。
  2. **sidecar GBK 输出**：Windows 管道下 Python stdout/stdin 默认随 locale（cp936），中文进程名/应用名一写即变 GBK 字节，宿主按 UTF-8 读行必炸；PyInstaller bootloader 会清洗 `PYTHON*` 环境变量（PYTHONUTF8 传不进内嵌解释器），故在 frida_bridge.py 源头 `reconfigure(encoding="utf-8")` 钉死。
  3. **同方法位探针静默顶掉**：`ov.implementation` 是替换语义，同 clazz.method 挂第二探针会杀掉先挂者（实测先挂者 hits 恒 0）→ addProbes 明确拒绝并提示先移除。
  4. **ensure() spawn 竞态**：诊断巡检（30s）与 UI 刷新并发首调会双 spawn 互杀 → spawn 单飞锁 + 双重检查。
  5. **crypto 穷举太慢**：27 组合串行百万级链式扫描（UI 自述「最长约几分钟」）→ 多线程并行（按提交顺序 join，候选顺序与串行版一致，语义不变）；cargo test 60s+ → 10.4s，UI 还原秒级。
  6. ResizeObserver loop 良性噪声不再弹 fatal 条。
